# 第三十三章. 组件规范与流式执行体验

![](../assets/ch04-workbench.jpg)


时间线上的块要能预测：气泡、计划卡、推理、错误。颜色来自 CSS 变量，不要在组件里写死 hex。流式增量必须零延迟；计划、步骤可以有一点展示间隔，让人看清顺序。后台标签页的 setTimeout 会被钳到一秒以上，所以 delta 绝不能进那套延迟。

思考过程用打字机节流。interval 不要挂在 text 依赖上，否则每来一个 delta 就重建定时器，永远走不到第一次 tick。
