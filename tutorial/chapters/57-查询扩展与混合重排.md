# 第五十七章. 查询扩展与混合重排

![](../assets/ch27-memory.jpg)


一条查询往往不够。扩展成几个变体，分别召回，用 RRF 融合。没有 LLM 时用规则改写。重排优先 LLM listwise，失败降到词法。TypeScript 还没有检索管线。接口一旦加上，trace 里应写下用了哪些变体、融合参数 k。不要把融合分数假装成模型置信度。
