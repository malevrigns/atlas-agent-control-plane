# 第四十八章. 键盘优先 TUI 客户端

![](../assets/ch04-workbench.jpg)


不是所有人都开浏览器。`frontend/tui` 仍是 Python Textual，这是客户端例外：后端已经是 TypeScript。TUI 打 `ATLAS_API_URL`，读同一份信封，列任务、看会话。后端挂了它进演示模式，不把栈甩在终端上。

快捷键以文档为准。不要和 Web 的 ⌘K 抢同一套肌肉记忆。颜色在真正的终端里看过再定，不要只在 IDE 的伪终端里调。
