# 第三十五章. 对话叙事、Markdown 与计划动效

![](../assets/ch04-workbench.jpg)


助手消息走 Markdown。流式时不要每字解析一遍，先 `<pre>`。落库后再用 `react-markdown`。GFM 表格要能横向滚，不要撑破整页。

链接协议白名单。CJK 紧贴 URL 时先插入空格再解析，否则链接会吞掉后面的中文。计划卡片展开步骤用 CSS 高度，不要 JS 量一堆 offsetHeight。
