# 第六十三章. 上下文预算与长任务耐力

![](../assets/ch13-loop.jpg)


长任务会把窗口撑爆。最近几步留全文，再往前变 digest，更早只留标题。硬上限是字符数，不是「尽量」。现在的 context 接口已经在数 included/omitted。执行机迁过来以后，用同一套数字卡步骤历史。

耐力不是让模型多聊两句。是预算、门禁、checkpoint 三件事一起把任务从第 1 步送到第 38 步还不至于失忆。教程写到这里，底板在 TypeScript 里已经能喘气、能记住会话、能把话推到浏览器。上面的机还在长。先把能跑的跑稳，再把剩下的门一扇一扇装上。
