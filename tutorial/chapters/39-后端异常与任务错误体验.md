# 第三十九章. 后端异常与任务错误体验

业务失败抛 `AppError`，带人能读的中文。未捕获的进 500 信封，细节留在日志和 request id。前端 `task_error` 事件画成错误卡，给重试。重试走 resume，不要把用户原话再插一条。

建议字段 `suggestion` 可以给「检查工作区路径」这种下一句。不要把栈当 suggestion。
