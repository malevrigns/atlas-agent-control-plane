# 第六十一章. 验收门禁与任务边界

![](../assets/ch13-loop.jpg)


任务说自己做完了不算。验收命令要 exit 0，范围审计看改过的文件是不是计划里的，覆盖度评审看测试是否盖住目标。三关共用重试额度。TypeScript 执行机还没接这三关。原则先成立：完成是挣来的。

命令用 spawn + 工作区 cwd，不要在 API 主机上随便 shell。越界就失败，不要让模型解释过去。
