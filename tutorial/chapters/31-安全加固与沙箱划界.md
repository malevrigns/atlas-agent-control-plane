# 第三十一章. 安全加固与沙箱划界

网关只绑 127.0.0.1。API Key 是单租户门闩，不是多用户账号体系。公网要上 TLS 和别人的身份层，不要把现在这套直接映射 80。

沙箱的根是 `/workspace`。`full_access` 仍出不了这颗卷。API 容器没有 Docker socket。MCP stdio 默认关。Markdown 链接只放行 http/https/mailto，`javascript:` 当文本。

![锁是给走神准备的](../assets/ch31-lock.jpg)

上传有大小上限。SSE 不走缓存。VNC 和 `/uploads/` 必须 auth_request。开发期 `API_AUTH_ENABLED=false` 可以，Compose 默认 true，start.sh 会生成随机 Key。

不要在日志里打印 Key、cookie、Authorization。request id 可以打，密钥不行。
