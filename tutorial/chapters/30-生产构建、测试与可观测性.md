# 第三十章. 生产构建、测试与可观测性

能跑不等于能改。`backend/api-ts` 用 vitest，不听端口。`pnpm test` 覆盖信封、鉴权 cookie、会话、SSE 序列。`sandbox-ts` 同样。CI 不再跑 Python 的 API 测试。

前端 `pnpm typecheck` 和 `pnpm build`。Compose 任务只做 `docker compose config` 和 nginx -t，不在 CI 里真的起浏览器。

![波形：看见它在动，才知道没死](../assets/ch30-observe.jpg)

日志至少带 request id。没有分布式追踪也行，先能把一次 curl 和一行 error 对上。`/api/observability/checks` 现在是空列表，工作台诊断页能打开。以后往里填「数据库能否 select 1、沙箱 status、磁盘是否可写」。

镜像：API 用 `node:22-alpine`，sandbox 用 bookworm-slim 因为要 apt 装 Xvfb。健康检查都是 node fetch，不要再写 python -c。
