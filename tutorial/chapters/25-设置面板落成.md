# 第二十五章. 设置面板落成

设置页是给运行时开关用的，不是第二份 `.env` 编辑器。模块启用、集成、LLM 是否配置，都从 `/api/config/app` 读。现在 TypeScript 返回一份空的但形状正确的 JSON，页面能打开，开关还落不了地。

密钥不要出现在这个接口里。只返回 `configured: true/false`。保存走单独的 PATCH，成功后重新拉快照。前端不要把 Key 写进 localStorage；登录用的是 HttpOnly cookie。

![工作台侧面那一排开关](../assets/ch04-workbench.jpg)

本地没有后端时，设置页应显示错误而不是假数据。假数据会让人以为模型已经接上。
