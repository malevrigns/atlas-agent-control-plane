## 本地运行

先启动后端 API，再启动 UI。

API 默认运行在：

```text
http://localhost:8000
```

UI 本地运行：

```bash
cd ui
pnpm install
pnpm dev
```

访问：

```text
http://localhost:3000
```

如果 API 不在 `8000` 端口，可以设置代理地址：

```bash
API_PROXY_URL=http://localhost:18000/api/:path* pnpm dev
```

## Docker Compose 运行

在项目根目录执行：

```bash
docker compose up -d --build
```

访问：

```text
http://localhost:8088
```
